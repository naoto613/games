# 灯庭のともり — ちいさな おにわ

スマートフォン・タブレットのChromeで、5歳前後の子どもがタップして遊ぶ庭づくりゲームです。6人の精霊と出会い、花や家具で居場所を整え、最後にみんなで灯樹をともします。戦闘、課金、時間制限、ゲームオーバーはありません。

## 起動

外部通信・画像ファイル・ライブラリ・ビルド不要の単一 `index.html`。リポジトリのルートで `python -m http.server 8765` を起動し、http://127.0.0.1:8765/tomori-garden/ を開きます。GitHub Pagesの静的配信でも動きます。

## タッチで遊ぶ

- **庭をタップ**：行きたい場所まで自分で歩きます。枝・石・仲間などをタップすると、近づいてから拾う・話す操作をします。
- **黄色の「いま やること」ボタン**：次の遊びを絵で案内。押すとそこへ歩き、採集・花植え・居場所づくりなどをします。白い点線が歩く道です。「とまる」で中断できます。
- **かざる**：花や、仲間から教わった家具を好きな場所に置けます。場所をタップ→「ここにおく」。自分で歩いて置きます。「おかたづけ」で回収。「おしまい」で通常の遊びに戻ります。
- **なかま**：絵本から仲間に会いに行けます。仲良くなった仲間はなでなでできます。いつでもしゃぼん玉遊びも選べます。
- **♪**：今することを日本語で読み上げます。
- **⚙**：保護者向けの音声・音量・演出・保存・データ入出力など。

キーボード操作・仮想スティック・手わざの細かな切替は子ども用画面から取り除きました。岩・枝・枯れ花・古い台座は、覚えた能力をタップで使えます。

## 遊びながら分かる6つの庭

最初に「仲間の庭を作るゲーム」と伝え、「庭を作る → 仲間が来る → 力を覚える」を3枚の絵で紹介します。仲間ごとに章が始まり、その子が好きな庭と作る理由を短い台詞で示します。画面上部には作っている庭の名前と、花・家具・贈り物の必要数／現在数を常時表示。達成した条件にはチェックが付きます。

最初のモフリの庭は花3つが条件。初期配置の1つに加え、プレイヤーが桃色・黄色・水色から選んだ花を2つ植えます。植えた場所に輪と花吹雪が出て、完成した庭には仲間の名前が付きます。次の水辺・休憩場所・風鈴・明かり・木陰の庭へと進みます。贈り物を集める理由と、もらえる力も会話で伝えます。

## 5歳向けの調整

ひらがな中心の短い案内、大きな絵のボタン、日本語読み上げ、正しい場所の光る目印、経路を探す自動歩行を組み合わせています。読み上げはWeb Speech APIと端末の日本語音声を使用するため、声の有無・品質は端末によります。音声なしでも絵と目印で案内します。

居場所に必要な札・家具・花の種はお手伝いとして補助し、複雑な材料計算を省略。自由配置も無料で行えます。仲間への贈り物用の素材採集と板・糸作りは、1つずつ案内します。お願いは種2、石2、板1、糸1、樹脂2、光片2。訪問待ちは最初2秒・以後3秒、素材再生は8秒。最終修繕は板3・石4・光片2、8秒です。

新規開始は確認画面で1.5秒の長押しが必要。失敗や不足で住人や家具を失わず、飾りの置き直しもできます。花・家具で通路を閉じる配置を拒否します。

## 描画・演出

オリジナルの多層Canvas描画。輪郭のある柔らかい配色に統一し、石畳、花壇の縁取り、庭の名札、衣装の縫い目・ポケット・スカーフ、精霊の表情と飾りを描き込みました。アイコン・背景・家具のキャッシュ画像は高解像度化し、スマホの拡大表示でぼやけにくくしています。陰影と木目のある家具、重なる葉、苔・小花・きのこ、樹木、波紋と岸辺、光るランタン、葉や花をまとった精霊、エプロン姿の庭師を描きます。呼吸・まばたき、歩行、蝶、光粒、成功時の花吹雪を加えています。キャラクターとアイテムの絵をそのままボタンや絵本にも使用。地形と静止物はキャッシュし、画面外を描画しません。DPRは2を上限にします。

絵と音はコードによるオリジナル。既存作品の画像・音・キャラクターは使っていません。

## 保存・旧版との互換性

ブラウザ内に15秒ごと・重要進行時の自動保存。localStorageの2世代保存、チェックサム、構造検証、JSON入出力に対応します。旧版のセーブはそのまま読み込み、配置・住人・所持品・解放済み能力を維持します。章の既読情報と花の色は追加の保存項目で、旧データにない場合も読み込み可能です。新しい景観の木は既存の配置・居場所・通路を邪魔しない場所だけ補います。

非表示タブとメニュー中は時間停止。オフライン経過では進みません。JSONの入出力とタイトルへの移動は保護者設定にまとめています。保存不可の場合は画面右下に表示します。

## 検証

```sh
# このフォルダーで
npm install
npx playwright install chromium
# 別ターミナル、リポジトリのルートで
python -m http.server 8765
# このフォルダーで
npm test
```

`CHROMIUM_PATH` でChrome/Chromiumの実行ファイルを指定できます。`TOMORI_TEST_URL` で検証先を変更できます。テストはタッチ対応Chromiumで行い、進行データへの素材注入や位置の瞬間移動なしに画面ボタンから全住人・能力・エンディングへ到達します。待ち時間と歩行時間のみシミュレーションを早送りします。最初の絵による説明、6章の導入、花の色選択、案内の重なり、自由配置、なでなで、しゃぼん玉、保存再開、旧形式、不正データ拒否、360×740・844×390・820×1180・1180×820の画面を確認します。

実機Chromeや5歳児本人によるユーザーテストはまだ行っていません。端末固有の読み上げや速度は実機で確認してください。
