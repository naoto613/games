# 灯庭のともり

環境を整えると精霊がやってくる、オリジナルの庭づくりゲームです。戦闘・捕獲・課金はありません。

## 起動

`index.html` を開くか、リポジトリのルートで `python -m http.server 8765` を起動して http://127.0.0.1:8765/tomori-garden/ を開きます。画像はCanvasによるオリジナル描画、音はWeb Audio合成。外部通信・ライブラリ・ビルド不要の単一HTMLです。静的配信を推奨します。

## 遊び方

WASD／矢印または左スティックで移動。近くの対象をクリック／タップで選び、Eまたは「調べる」で採集・会話・作業台を使います。Bで建築、Iでバッグ、Jで手帳。建築中は矢印でマスを選び、Enterで配置、Rで向き、Xで回収。歩くときは閉じます。手わざは「選ぶ」で切替、手わざボタンまたはSpaceで使用します。PCでは1〜5でも選べます。

枝を3つ拾うと札が手に入ります。最初は(7,32)に札を置き、草4・花2の居場所を整えて10秒待ちます。モフリに話しかけて種3を渡しましょう。作業台(9,34)で家具を作り、手帳の条件に沿って新しい仲間を迎えます。

## 進行

|仲間|札のおすすめ位置|条件|お願い|報酬|
|---|---|---|---|---|
|モフリ|(7,32)|草4・花2|種3|芽吹き|
|シズネ|(12,10)|水3・石飾り2・草2|石3|潤し|
|コロガ|(17,30)|石飾り2・腰掛け1|板2|砕き|
|ヒララ|(33,37)|花3・風鈴1|糸2|風払い|
|ホノト|(39,29)|小灯り2・腰掛け1|樹脂3|灯し|
|ヨルネ|(36,10)|木陰3・小灯り2・小屋1|光片3|灯樹修繕|

前の仲間のお願いを叶えると次の仲間を迎えられます。札を中心に5×5を判定し、札同士は範囲を重ねられません。モフリ以外は条件を連続20秒満たすと訪問。草と花は重複計数しません。鉢花は花として数え、水鉢は水地形としては数えません。

岩の入口は(24,34)、枝の入口は(34,23)。全員のお願いを叶えたら、北の灯樹(36,5)へ。板8・石12・光片6を使って30秒修繕すると完成です。その後も庭づくりを続けられます。

## 保存

15秒ごとと重要進行時に自動保存。localStorageの2世代保存、チェックサムと構造検証があります。設定からJSON入出力、手動保存、入口への帰還ができます。ローカルファイルではブラウザによって保存が使えない場合があります。保存結果は画面右下で確認してください。ゲームが非表示、会話・メニュー中は時間が停止し、オフライン経過では進みません。

## 実装範囲

設計書の主要な遊びの流れ（48×48・4区画、6住人、5能力、8目標、12配置物、素材再生、共同修繕、PC・タッチ、保存）を実装。描画は固定見下ろしCanvas、住人は居場所内の経路で歩きます。画像スプライト、独立TypeScriptモジュール、Vite、複雑な交流演出は使用せず、配布HTMLに直接まとめています。回転情報は保存しますが、現在の家具は向きによる外観差がありません。

## 検証

```sh
npm install
npx playwright install chromium
# 別ターミナル、リポジトリのルートで
python -m http.server 8765
# このフォルダで
npm test
```

テストはローカルの使い捨てブラウザで実行。初期採集は実際のUI、全住人の判定と報酬・区画開放・保存・完成はゲーム関数によるシミュレーションで確認します。45〜90分の初見プレイ時間と全端末での操作感は未計測です。

## 素材

絵・音はこのゲームのコードによるオリジナル。既存作品の画像・音・キャラクターは使用していません。
