# ハーモニーランド攻略ナビ（非公式）

サンリオキャラクターパーク ハーモニーランド（大分県速見郡日出町）を訪問する日に、整理券・ショー・施設・回り方をスマートフォンで確認するための静的 Web アプリです。公式アプリ・公式サービスではありません。

- 対象日：**2026年10月13日（火）**
- 対象端末：スマートフォン・タブレット（Google Chrome）
- 情報収集対象期間：2025年10月13日〜2026年10月13日
- データ作成日：2026年10月10日（同日、利用者提供の統合資料と園内マップ画像で更新）

## 起動方法

| 方法 | 手順 | 備考 |
| --- | --- | --- |
| Web で開く | https://naoto613.github.io/games/harmonyland-guide/ | 一度開くと Service Worker が保存し、通信できなくても基本情報を見られる |
| ZIP を展開してファイルで開く | `harmonyland-guide.zip` を展開し `index.html` を Chrome で開く | `file://` では JSON を読めないため、同梱の `js/data-fallback.js` を使う。オフライン用の Service Worker は動かない |
| ローカルサーバー | `cd harmonyland-guide && python3 -m http.server 8000` → http://localhost:8000/ | 開発・確認用 |

## 情報の更新方法

アプリは公式サイトから情報を自動取得しません。データファイルを編集して更新します。

1. 公式サイト（営業カレンダー・アトラクション・FAQ・ファンスタジオのスケジュール・イベント特設ページ）を開いて内容を確認する。
2. `data/*.json` を編集する。
   - 確認した出典は `sources.json` の `checkedAt`（実際に本文を確認した日時）・`updatedAt`（ページの更新日。分からなければ `null`）・`verificationStatus` を更新する。
   - 対象日の営業時間が分かったら `opening-info.json` の `status` を `"confirmed"`、`openingTime`／`closingTime` を入れる。
   - ショーの当日時刻が公式スケジュールで確認できたら、`shows.json` の `schedule` の該当日に `startTime`／`endTime` と `"status": "confirmed"` を入れる。確認できるまでは `null` のままにする（期間中の通常時刻は `announcedTimes` に入れ、画面では「参考」と表示される）。
   - 施設の位置が資料で確認できたら `location.x`／`location.y`（模式図に対する 0〜1 の相対座標）と `positionSource`（根拠資料）を入れる。マップ画像を差し替える場合は `assets/map-base.svg` を置き換え、`js/map.js` の `MAP_RATIO`（縦/横）を合わせる。
   - 各施設・イベントの `lastVerifiedAt` に確認日時を入れる。
3. `python3 build.py` を実行して `js/data-fallback.js` と `harmonyland-guide.zip` を再生成する。
4. Web 版は `sw.js` の `CACHE` 名を変えると古いキャッシュが確実に入れ替わる（データはネットワーク優先なので、通常は再読み込みで反映される）。

再確認のタイミング：**来園前**（営業カレンダー・イベント・整理券）、**当日朝**（営業時間・ショー・整理券・休止）。

## 主な機能（2026年10月10日の追加分）

- **子どもの年齢**（プラン画面で設定）：公式一覧の「○歳未満は利用不可」「○歳未満は保護者同伴」と照らし合わせ、施設ごとに「利用不可／保護者同伴が必要／掲載の年齢条件に該当なし／条件未確認」を表示。身長・体重・当日の運行は判定しない。条件が不明な施設を「乗れる」とは判定しない。一覧の「子どもの年齢で利用できる」で絞り込める。
- **雨の日モード**（プラン画面）：プランのうち雨天・強風で運休と掲載されている施設を示し、運休の掲載がない施設を代わりの候補として出す（屋内かどうかは未確認と明示）。
- **時間割**（プラン画面）：自分で時刻を入れた予定と、公式に案内された参考時刻のショーを時刻順に並べる。
- **モデルプラン・優先順位**、**確認チェックリスト**（来園前／園内、ホーム）。
- **整理券**：取得場所・受付開始・参加時間・料金・定員・受付終了条件・過去の情報を別々に表示。早い時刻のものから並べる。任意の有料券（最前列）と優先券の当日確認項目も表示。
- **ショー**：出演キャラクター・観覧ルール・参加グッズ。
- **マップ**：利用者提供の園内マップ画像から、エリアの配置と施設の位置を読み取って独自に作図（元画像は含めていない）。地図上に名前が書かれていた場所は実線のピン、番号と公式アトラクション一覧の掲載順から推定した場所は点線の「推定」ピン。番号 8〜15 は施設名との対応が確定できないため灰色の番号のみ表示。雨天・強風で運休するもの、整理券、ショー会場はピンに記号を付ける。

### 位置データの根拠

地図の番号 1〜7 は、1＝お城の絵、3＝2つの駅、7＝観覧車の絵が公式一覧の 1・3・7 番目（キティキャッスル・ハーモニートレイン・大観覧車）と一致するため、間の 2・4・5・6 も掲載順どおり（リズミックコースター・Sky Pal Collection・ファンスタジオ・EVゴーカート）と推定した（`positionStatus: "reference"`）。8〜15 は番号が 8 個に対して残りの施設が 7 個で対応が決まらないため、位置を登録していない（ボートライドは「のりば」の表記から位置を登録）。

## 未確認情報の扱い

- 状態は `confirmed`（確認済み）・`scheduled`（開催予定）・`reference`（参考情報）・`day_of_check`（当日要確認）・`unconfirmed`／`unverified`（未確認）・`changed`（変更あり）・`expired`（期限切れ）。色だけでなく記号と文字でも表示する。
- 値が `null` の項目は空欄にせず「未確認」「公式情報を確認してください」と表示する。推測で補完しない。
- 整理券・予約の要否は `true`（必要）／`false`（不要）／`"unknown"`（未確認）で持ち、要否と取得方法（`admission`）を別々に管理する。
- 「公式ページに掲載されている」ことと「対象日に実施される」ことは別に扱う。開催期間中のイベントでも、対象日の公式スケジュールで確認するまでは当日の確定情報として表示しない。
- 確認できない施設は作らない。飲食店・ショップ・ベビーセンター・インフォメーションなどは公式FAQ・イベントページに名前がある施設だけを登録し、位置が分からないものは一覧から探せるようにしている。
- 公式のマップ・画像・ロゴ・キャラクター画像は複製していない。
