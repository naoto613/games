### 0-2 の 決めごと（データの 作りかた）
- 名前・系統・属性・特徴は 仕様書の表のまま。Q1 で 093→クラウドウィング、108→タイドサーペント に改名。
- 役割は 特徴の文から自動判定し、合わないものを `OVERRIDES` で手直し。ランクは 系統内の番号（1〜6→★1、7〜12→★2、13〜→★3）を基本に、伝説級（★5）・ボス由来や高位（★4）・出現章に合わせた補正。
- 能力 = 役割テンプレート（v1 の値を7能力に分けたもの）× ランク倍率 × 成長型補正。
- 耐性 = 系統の基本耐性 ＋ 自分の属性に強い ＋ 弱点属性に弱い（弱点が消えた種には系統ごとの予備の弱点）。
- 習得スキル・生息地は 0-5／Phase 1 で埋める。

### 0-3 の 決めごと（ドット絵の 切り出し）
- 参考画像1の 10パネルを タイトル帯の 位置で 特定し、各段の「絵→番号→名前」の 行の かたまりから 絵の 段（4段）と 5列を 自動で 見つける。ID は マスの 位置（行優先）で 決める（Q3）。
- 背景は マスの 外周の 色から 推定して 外がわから 塗りつぶして 抜く。白い ハイライトを 消さないため「囲まれた背景」の 除去は 個体指定のときだけ（`ENCLOSED`）。本体より 下の 部品（番号の 文字）は 除く。32色に 減色し、外がわだけに 1px の りんかくを つける。
- 原寸（約40px）のまま 64×64 の 中央下（足もと y=58）に 置く。りんかくを 含めて 48px を こえる 20体は 大型として 96×96（足もと y=88）。表示時は キャンバスの 大きさに 比例して 大きく 見せる（0-4）。
- 待機・攻撃・被弾・戦闘不能の モーションは 0-4 で 1枚絵から 手続き的に 作る（Q6）。

### 0-4 の 決めごと（表示）
- ID が `m###` の ときは アトラスから、それ以外（v1 の 種族）は 今までの データから 描く。v1 → v2 の 切りかえ（戦闘・図鑑・配合で v2 の 種族を 使う）は 0-5 で 行う。
- 通常の 絵は キャンバスごと 2倍（64→128、大型 96→192）。戦闘では 足もとを そろえ、高さ 184px を こえる ときは 縮める。アイコン・ついてくる 仲間は 絵の 範囲だけを 切りだす。
- アトラスが 読めなかった ときは「?」の かわりの 絵（未完成アセット あつかい）を 出し、読めた あとに 正しい 絵に かわる。

### 0-5 の 決めごと（7能力・8属性）
- 能力：hp / mp / attack / defense / speed / magic（魔力）/ spirit（精神）。v1 の 種族は かしこさを 魔力・精神の 両方に 入れる。精神は レベルアップで 魔力と 同じ 乱数を 使う（v1 と 同じ 乱数の 流れ＝v1 の バランステストが そのまま 通る）。
- 呪文 = 威力 ＋ 魔力×0.12（全体は半分）− 精神×`spiritScale`。回復 = 威力 ＋ 魔力×0.25 ＋ 精神×`healSpiritScale`。精神の 係数は Q13 どおり 0 から はじめ、Phase 1 以降の バランス調整で 上げる。
- 属性：火・水・風・地・雷・氷・光・影。v1 の やみの 特技（ダークウェーブ など）は 影属性に した。耐性 4 = 吸収（ダメージぶん 回復。AI は 吸収される 特技を さける）。吸収を もつ 種は まだ 0（ボス・特殊役で 数を しぼって 使う）。
- 成長6型：早熟・晩成 = 全能力の 曲線、攻撃特化・耐久 = 能力の かたより（0-2）、均衡 = ふつう、変則 = 戦闘中に HP が 半分を 切ると 1回だけ 覚醒（こうげき・まりょく +1段階）。
- 特技の 追加効果：`drain`（与えたダメージの 割合を 吸いとる）、こうげき 特技の `statusEffectId`（ついでに 状態異常。v1 の でんきショックの まひ も 有効に なった）。強化・弱体は 魔力・精神も 対象に。
- 習得スキル：属性ごとの 特技セット × 役割の 並び × 特徴の ことば（毒・麻痺・眠り・吸収 など）× ランクで 自動生成し、系統らしい 物理技を 選ぶ。伝説級（★5）だけ 固有特技（受け継げない）。個別の 手直しは `LEARNSET_OVERRIDES`。
- v2 の 200種は 種族表（`SPECIES`）に 登録ずみで 戦闘・成長・配合の エンジンで 使える。図鑑・出現・ボス・はじめの 仲間の 切りかえと 旧セーブの 種族変換は 0-10 で 行う（それまで 遊べる 内容は v1 の まま）。
