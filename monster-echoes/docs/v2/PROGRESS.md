### 0-2 の 決めごと（データの 作りかた）
- 名前・系統・属性・特徴は 仕様書の表のまま。Q1 で 093→クラウドウィング、108→タイドサーペント に改名。
- 役割は 特徴の文から自動判定し、合わないものを `OVERRIDES` で手直し。ランクは 系統内の番号（1〜6→★1、7〜12→★2、13〜→★3）を基本に、伝説級（★5）・ボス由来や高位（★4）・出現章に合わせた補正。
- 能力 = 役割テンプレート（v1 の値を7能力に分けたもの）× ランク倍率 × 成長型補正。
- 耐性 = 系統の基本耐性 ＋ 自分の属性に強い ＋ 弱点属性に弱い（弱点が消えた種には系統ごとの予備の弱点）。
- 習得スキル・生息地は 0-5／Phase 1 で埋める。

### 0-3 の 決めごと（ドット絵の 切り出し）
- 参考画像1の 10パネルを タイトル帯の 位置で 特定し、各段の「絵→番号→名前」の 行の かたまりから 絵の 段（4段）と 5列を 自動で 見つける。ID は マスの 位置（行優先）で 決める（Q3）。
- 背景は マスの 外周の 色から 推定して 外がわから 塗りつぶして 抜く。白い ハイライトを 消さないため「囲まれた背景」の 除去は 個体指定のときだけ（`ENCLOSED`）。本体より 下の 部品（番号の 文字）は 除く。32色に 減色し、外がわだけに 1px の りんかくを つける。
- 原寸（約40px）のまま 64×64 の 中央下（足もと y=58）に 置く。りんかくを 含めて 48px を こえる 20体は 大型として 96×96（足もと y=88）。表示時は キャンバスの 大きさに 比例して 大きく 見せる（0-4）。
- 待機・攻撃・被弾・戦闘不能の モーションは 0-4 で 1枚絵から 手続き的に 作る（Q6）。

### 0-4 の 決めごと（表示）
- ID が `m###` の ときは アトラスから、それ以外（v1 の 種族）は 今までの データから 描く。v1 → v2 の 切りかえ（戦闘・図鑑・配合で v2 の 種族を 使う）は 0-5 で 行う。
- 通常の 絵は キャンバスごと 2倍（64→128、大型 96→192）。戦闘では 足もとを そろえ、高さ 184px を こえる ときは 縮める。アイコン・ついてくる 仲間は 絵の 範囲だけを 切りだす。
- アトラスが 読めなかった ときは「?」の かわりの 絵（未完成アセット あつかい）を 出し、読めた あとに 正しい 絵に かわる。

### 0-5 の 決めごと（7能力・8属性）
- 能力：hp / mp / attack / defense / speed / magic（魔力）/ spirit（精神）。v1 の 種族は かしこさを 魔力・精神の 両方に 入れる。精神は レベルアップで 魔力と 同じ 乱数を 使う（v1 と 同じ 乱数の 流れ＝v1 の バランステストが そのまま 通る）。
- 呪文 = 威力 ＋ 魔力×0.12（全体は半分）− 精神×`spiritScale`。回復 = 威力 ＋ 魔力×0.25 ＋ 精神×`healSpiritScale`。精神の 係数は Q13 どおり 0 から はじめ、Phase 1 以降の バランス調整で 上げる。
- 属性：火・水・風・地・雷・氷・光・影。v1 の やみの 特技（ダークウェーブ など）は 影属性に した。耐性 4 = 吸収（ダメージぶん 回復。AI は 吸収される 特技を さける）。吸収を もつ 種は まだ 0（ボス・特殊役で 数を しぼって 使う）。
- 成長6型：早熟・晩成 = 全能力の 曲線、攻撃特化・耐久 = 能力の かたより（0-2）、均衡 = ふつう、変則 = 戦闘中に HP が 半分を 切ると 1回だけ 覚醒（こうげき・まりょく +1段階）。
- 特技の 追加効果：`drain`（与えたダメージの 割合を 吸いとる）、こうげき 特技の `statusEffectId`（ついでに 状態異常。v1 の でんきショックの まひ も 有効に なった）。強化・弱体は 魔力・精神も 対象に。
- 習得スキル：属性ごとの 特技セット × 役割の 並び × 特徴の ことば（毒・麻痺・眠り・吸収 など）× ランクで 自動生成し、系統らしい 物理技を 選ぶ。伝説級（★5）だけ 固有特技（受け継げない）。個別の 手直しは `LEARNSET_OVERRIDES`。
- v2 の 200種は 種族表（`SPECIES`）に 登録ずみで 戦闘・成長・配合の エンジンで 使える。図鑑・出現・ボス・はじめの 仲間の 切りかえと 旧セーブの 種族変換は 0-10 で 行う（それまで 遊べる 内容は v1 の まま）。

### 0-6 の 決めごと（ボスの 行動台本）
- ふだんの 行動は 今までどおり AI が 決め、台本は「いつ（開始・nターンごと・HP が 割合以下・子分が n体未満）× なにを（台詞・召喚・反射・強化・形態変化・属性切替・強化解除・特技の 指定）」を くわえるだけ。`inPhase` で 形態ごとに ルールを 切りかえる。`once` で 一度きり。
- 召喚：場の 敵は 最大4体。子分は 経験値・お金なし・仲間に ならない。同じ 名前には A/B… を つける。画面では `summon` イベントで すぐ 表示。
- 反射：呪文・息を 使い手に はねかえす かがみ。物理で 決まった 回数 なぐると われる（ミラージュの「物理に 切りかえる 判断」）。ターン経過でも 消える。
- 形態変化：名前・能力倍率・特技・耐性を かえ、HP を 回復。状態異常と 反射は 解除。
- 属性切替：その 属性に「とてもつよい」、弱点の 属性に「よわい」へ じゅんに 切りかわる。
- 実際の ボス戦への 割りあては Phase 1 以降（各章の ボスを 作るとき）。

### 0-7 の 決めごと（章・街・機能）
- 章は 仕様6の とおり 3ステージ（街 → ダンジョン → 章ボスの ダンジョン。第12章だけ ダンジョン3つ）。ステージは 順番に すすみ、先の 章には 入れない。クリアずみの ステージには 何度でも 入れる。
- 機能は「街に 着いたとき」（仕様6 の 各ステージの 解放）と「章クリア」（仕様15）に 解放。両方に 同じ 機能が ある ときは 先に 来た 方で 解放（配合は ミズナ到着、仲間・図鑑・旅の扉は 第1章クリア）。
- 街は 大きな 街6（リーフェル・ミズナ・カゼノ・アカリス・フロスト・アステラ）と 小さな 拠点5（エルム・ボルカ・シェルナ・ノクサ・記憶の門）（Q7）。推奨レベルは Q15 の 表。
- 仕様の ダンジョンは 本編25（＋クリア後3）。Q7 の「本編27」との 差（寄り道 9 と あわせて 調整）は Phase 2 以降の 寄り道ダンジョンで うめる。
- セーブの `chapters` は いまは 任意（ない ときは 第1章の はじめ）。0-10 の 引き継ぎで 必ず 持つように する。

### 0-8 の 決めごと（物語）
- 物語イベント = きっかけ（ステージに 着く・クリア・n階・ボス撃破・会話・手動）× 条件（章・ステージ・フラグ・見た・機能・街・パーティ・所持・どれか）× 台詞 × 反映（フラグ・道具・仲間・お金・回復・ステージクリア・記録室）。ふつうは 一度きり、`once:false` で 何度でも。重要な イベントは 抽選に しない（仕様 4.3）。
- NPC は 会話表を もち、条件に あう ものの うち 優先度 → あとに 書いた ものの 順で えらぶ（章ごとに かわる）。
- ルナスライムの 反応は 場面（歪み・紋章・ボスの記憶・原初の光・街・ふだん）ごと。相棒が パーティに いる ときだけ。一度きりの 反応が 先。
- 台詞の `{name}`・`{luna}` は 主人公・相棒の 名前（ニックネーム）に おきかえる。
- 伏線は `record` で 記録室に のこし、あとから 読みかえせる（仕様 17.3）。画面への つなぎこみは Phase 1。

### 0-9 の 決めごと（フロア生成）
- 格子（3×3・4×2、最後の階は 3×2）の マスに 部屋テンプレートを 1つずつ 置き、ランダムな 木（＋15% の 回り道）で つなぐ。通路は 部屋の 外（マスの さかいめ）で 曲がるので 部屋を 横切らない。
- スタートは 行き止まりの 部屋、階段（最後の 階は ボス）は スタートから いちばん 遠い 部屋。固定イベントは 行き止まりに 近い 部屋の 置き場（*）に 必ず 置く。隠しイベントは 余った とびらを 隠し扉（Z）に して その 奥。
- ギミックは タイルの 上に 重ねる 層（`gimmicks`）：毒の床（1歩ごとに 最大HP の 3%、`BALANCE.dungeon.poisonFloorRate`）、水流（流れの 向きに 押し流す）、氷（止まるまで すべる）、スイッチと 扉（ゴールの 部屋の 入口を 閉じる）。
- 検査：スタートから（すべり・スイッチも ふくめて）階段・宝箱・イベント・泉・出口に 届くこと、行った 場所から スタートへ 戻れること（水流の 閉じこめ防止）。だめなら 作りなおす。
- 既存の v1 ダンジョン（`FloorGen.ts`）は そのまま。v2 の ダンジョンへの 組みこみ（各ステージの ギミック指定・描画・毒の床の ダメージ）は Phase 1 で 行う。

### 0-10 の 決めごと（セーブと 引き継ぎ）
- SCHEMA の 流れ：v3→v4（0-5：かしこさ → 魔力・精神）、v4→v5（0-10：v2 の 進行の 欄を 追加。物語は 第1章から）。v1・v2 の セーブも 順に 移行して 読める。移行の まえに 元の データを `backup-<時刻>` に のこす（IndexedDB・メモリ版とも）。
- v1 の 進行（エリア・ボス・闘技場の フラグ）は いま 遊べる 内容の ために v5 でも のこす。
- 引き継ぎ（Q9）は `inheritLegacy()`：種族を 対応表で v2 に（系図・図鑑・配合履歴も）、耐性は v2 の 種族の もの、レベル・＋値・とくぎ・ニックネーム・道具・お金・牧場は そのまま、個体の 履歴に「引き継がれた」を 記録、物語・進行は 第1章から。何度 よんでも 同じ 結果。
- **実行は Phase 1 の 切りかえ時**（v5→v6 の 移行として 登録）。いま 実行すると v1 の エリア・ボスと v2 の 種族が まざるため（計画の「Phase 0 は 見た目の 変化を 最小限」に したがう）。

### P1-A の 決めごと
