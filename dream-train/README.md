# ふーちゃんの にじいろまち大冒険

既存の子供向け13作品の特徴的な遊びを、同じ主人公・町・持ち物・物語で遊ぶ新作です。リッキーをあやして得たリボンで着替え、診療のお礼のスキャナーで町の正体を調べ、工作で架けた橋を渡って宝を探します。最後はみんなの力でお祭りの光を取り戻します。

各作品のタイトルや別ページへの移動はありません。町を歩いて人物や物を調べ、その場の拡大シーンで遊びます。スキャナーは町の人物に直接かざす道具です。モンスター・エコーズと灯庭のともりは組み込んでいません。元作品の全ステージ・全機能の移植ではなく、下記の遊びを共通の物語に再構成しています。

## 操作と保存

- 町の地面をタッチして歩く。ドラッグで周囲を見渡す。右上の「◎」で主人公へ戻り、「−」で広く見る。
- 人物や建物をタッチすると、歩いて近づいて調べる。町は矢印キー、調べるボタンはキーボードでも操作できる。
- 道具はドラッグまたは「選ぶ→置く」で使える。スキャナーは持ち物から選び、町の人物にかざした後「キャッチ」へ切り替える。
- 右上の音符で任意の日本語読み上げと効果音を有効にできる。動きを減らす設定では町の移動が即時になる。
- `localStorage['nijiiro-town.adventure.v2']` に進行、衣装、位置、捕獲済みの人物、お祭りの飾りを保存。音声は同キー末尾 `.voice` に保存。
- 手伝いの途中で閉じた拡大シーンは再挑戦になる。完了した手伝いとスキャナーの途中経過は保持する。
- 旧列車版の `dream-train.v1` と元の各ゲームの記録には書き込まない。「はじめから」もこの冒険の記録だけをリセットする。
- 保存を使えないブラウザでもその場で遊べるが、ページを閉じると進行は失われる。

## 構成

- `story.js`: 手伝いの依存関係、共通持ち物、進行と保存データの検証。
- `town.js`: 主人公の移動、カメラ、町の変化、手帳、道具と保存。
- `town-art.js`: 町と小道具のSVG、既存キャラクター描画の組み合わせ。
- `activities.js`: 同じ物語の拡大シーン、町に直接作用するスキャナー、当たり判定と時間処理。
- `town.css`: PC・タブレット・スマートフォンの画面。
- `../kirameki-princess/js/art-char.js`: 元のキャラクターの衣装・髪型の描画。
- `../nijiiro-treasure/art.js`: 仲間・植物・道具などの共通SVG。

ビルド不要。外部CDN、WebGL、iframeは使わない。共有アートを参照するため、リポジトリ全体でHTTP配信してください。

## 検証

```sh
# リポジトリのルート
python3 -m http.server 8771
# http://localhost:8771/dream-train/

node dream-train/tests/story.cjs
node dream-train/tests/play.cjs
node dream-train/tests/runtime.cjs
```

ブラウザテストはPlaywrightとChromiumを使用します。配信先は `TOWN_TEST_URL`、ブラウザは `CHROMIUM_PATH` で変更できます。

進行ルールのテストでは依存関係、報酬の重複防止、順序の異なる寄り道、壊れた保存の回復を確認します。ブラウザでは実際の操作で最初のお世話から全14の出来事とお祭りまで進み、衣装と道具の共有、町でのスキャン、発掘、保存からの再開、飾りつけ、5画面サイズ、読み込みエラーとiframe不在を確認します。

追加の実行時テストでは通常速度でのキーボード移動、橋の通行条件、スキャナー途中再開とキーボード操作、道具を持った状態からの再スタート、保存が拒否された場合の継続プレイを確認します。
