# モコの ひみつアトリエ

**さわって、つくって、大発見！** 道具で舞台そのものに働きかけ、発見した部品で自分の空飛ぶアトリエを育てる、5歳ごろからの遊びの実験室です。

既存作品の遊びを手掛かりに、キャラクター・体験・画面・進行・アートを新しく設計しています。「ぴょんたの にじいろ たからさがし」のエンジン、アート、マップ、セーブは使いません。元ゲームの起動やiframeはなく、このフォルダだけで動きます。モンスター・エコーズと灯庭のともりは組み込んでいません。

## 体験の中心

1. **触ると返事がある。** 最初は眠っているモコをなでたり引っ張ったりして起こす。水たまり、きのこ、雲、惑星にも違う反応がある。
2. **同じ物に違う道具を試す。** 花を育て、現れた蝶を撮り、写真を風車に届けて工作する。雨雲の写真をサンゴに渡すと、写真から雲が現れ、雨が降る。ジョウロで育てる別の解き方もある。
3. **成果が自分の場所に残る。** 森・海・星で得た9つの部品がアトリエを3段階で育てる。飾りを24個まで自由に置き、動かし、回し、大きさを変えて、自分の部屋を作る。
4. **一度で終わらない。** 各世界をひと通り遊ぶと「あたらしい ふしぎ」を選べる。各3種類のクイズ、探す相手、音列、工作、暗号を遊び、27の重複しないひらめきを集める。世界の飾りや色も変わる。
5. **自分だけの発見と写真。** 36の発見は実際の操作と条件に対応する。図鑑の未発見カードには道具のヒントがある。直近12枚の写真に、そのときの姿・舞台の状態・アトリエの飾りを残し、PNGとして保存できる。過去の写真を選び直して持ち歩くこともできる。

時間切れやゲームオーバーはありません。見つかったときも拾った部品は保持し、クイズや音の間違いは再挑戦できます。大きな絵、選択中の道具、舞台の光る目印、次の操作を示す絵のヒントを優先しています。

| 世界 | 主な出来事とつながり | 遊び直しで変わるもの |
| --- | --- | --- |

スコープと魔法は冒険で届く道具です。スコープ内だけに見える正体を調べた後、魔法で宇宙の友達と挨拶できます。以前の世界へ帰ると、花を虹色にしたり、サンゴの泡を見つけたりする発見もあります。

参考にした既存作品の特徴は、リッキーの触感、プリンセスルームの着せ替え、病院の処置手順、動物クイズ、人混みの視覚探索、ぺたぺたの配置と見立て、スナップの因果の連鎖、エイリアンのスコープ、森とこっそりトレジャーの視界・隠れ場所・足音、探偵の数字・英語・防御と魔法、宝探しの観察や道具の使い分けです。元作品の全機能の移植ではありません。

## 操作と配慮

- 道具を選んで舞台の物をタッチ。お世話の道具、写真、工作の部品、飾りはドラッグでも使える。
- 工作は形と向きを照合し、回すボタンで90度ずつ回転する。形の上の印も向きの手掛かりになる。
- モコは引っ張ると伸びて戻る。飾りは置いた後もドラッグで動かせる。選んだ飾りは回転・サイズ変更・削除ができる。
- 隠密は地面または部品をタッチして移動。隠れ場所で休み、走る速さと足音も選べる。矢印キーでも動く。
- キーボードで道具・人物・選択肢・工作を操作可能。置いた飾りは矢印で移動。最後の魔法はSpace/Enterの長押しにも対応する。
- 声と効果音は任意。日本語読み上げはブラウザが提供する声を使う。動きを減らす設定では移動装飾や撮影フラッシュを抑える。タイミングのある防御は操作する遊びとして残す。
- スマートフォンは舞台と道具のトレイで画面の高さを分ける。小さな画面では操作領域を確保するため縦スクロールできる。横にはみ出さない。

## 保存と構成

保存キーは `localStorage['moco.atelier.v1']`。進行、世界ごとの途中経過、衣装、発見、写真、配置を保存します。隠密の移動位置や音の入力途中、魔法の充填は再開時にやり直しですが、回収済みの部品や成功済みの防御は残ります。ブラウザで保存が拒否された場合も、その場では遊べるように案内します。

旧版の `nijiiro-town.adventure.v2`、列車版、元の各ゲームの保存には書き込みません。「最初から」はこの冒険だけをリセットします。

- `lab-core.js`: 道具の作用、依存関係、3種類のパズル、報酬、36の発見、写真と保存データの検証。
- `lab-art.js`: 新規キャラクター・道具・反応・背景の補助描画・状態を反映した写真のSVG。
- `lab-ui.js`: 同じ舞台への入力、触感、写真の雨、工作、スコープ、音列、隠密、防御、自由制作、アルバムとPNG出力。
- `lab.css`: 新しい画面と動き、スマートフォンの配置。
- `assets/*.webp`: このゲーム用に生成したキービジュアルと3世界の背景。4枚合計約780KB。外部CDNやネットワーク上の素材に依存しない。

ビルド不要。このフォルダをHTTP配信すれば遊べます。

## 起動と確認

```sh
python3 -m http.server 8771
# http://localhost:8771/dream-train/
node dream-train/tests/core.cjs
node dream-train/tests/journey.cjs
node dream-train/tests/runtime.cjs
```

ブラウザテストにはPlaywrightとChromiumを使用。`MOCO_TEST_URL` と `CHROMIUM_PATH` で配信先・実行ブラウザを変更できます。

- ルールのテストで9つの出来事×3種類、36の発見すべてへの到達、重複しない27の報酬、道具や向きの条件、写真の状態、保存の検証を確認。
- ブラウザでは進行を注入せず、モコを引っ張って起こすところから全9つの出来事とショーまで実際に操作。着せ替え、間違った処置、クイズの再挑戦、写真の受け渡し、向きのある工作、24人の探索、音列、視界の中を移動する隠密、3回の防御、充填の魔法を通す。
- 続けてスコープ、前の世界での新たな魔法、遊び直し、家の飾り、PNGの実ファイル、再読み込み、5画面サイズ、iframe不在、読み込みエラーを確認。
- 実行時テストではタッチ・キーボード、置いた飾りの編集、道具のドラッグ、電話画面内の道具、保存を拒否された環境でも遊べることを確認。
