# ぴょんたの にじいろ たからさがし

5歳前後向けの、絵のヒントを使った宝探しゲーム。既存の「ふーたんを さがせ！」の絵本調の色づかい、「どうぶつ クイズ」の音声案内・失敗してもやり直せる設計、「きらめきプリンセスルーム」のうさぎのぴょんたを参考にしています。

## 遊び方・企画

- 森・浜辺・空から好きな島を選ぶ。すべて最初から遊べます。
- ヒントの絵と同じものをタップし、かぎを3つ見つけて宝箱を開けます。1回の冒険は約1〜3分。
- 探す順番と配置は冒険ごとに変わります。間違えても減点やゲームオーバーはありません。
- ヒントボタン、2回の間違い、12秒の待機で正解の場所を光らせます。色だけに頼らず、絵・形・名前でも見分けられます。
- 各島に3種類、全9種類の宝物。同じ島で繰り返し遊ぶと未取得の宝物が優先されます。全部集めても遊べます。
- ひらがな中心の案内、大きなタップ領域、キーボード操作、動きを減らす設定に対応。
- 音は最初オフ。「♪ きく」または上部の音ボタンで効果音と日本語読み上げを有効にします。音声が使えなくても、絵と表示だけで完結します。
- 宝物・かぎの進行・音設定を localStorage に保存します。「しまの ちず」に戻って同じ島を選ぶと再開。他の島を選ぶと、その島の新しい冒険が始まります。保存不能・不正な保存データでも遊べます。

## 起動

ビルド・外部素材・外部フォント・通信は不要。`index.html` を直接開くか、リポジトリのルートで以下を実行します。

```sh
python3 -m http.server 8765
# http://localhost:8765/nijiiro-treasure/
```

`art.js` はオリジナルの SVG 描画、`game.js` は進行・保存・音、`style.css` はスマートフォン／タブレット／PC用のレイアウトです。

## 検証

Playwright と Chromium が入った環境で、上記のサーバーを起動して実行します。

```sh
node nijiiro-treasure/tests/play.cjs
```

`TREASURE_TEST_URL` で対象 URL、`CHROMIUM_PATH` でブラウザの実行ファイルを変更できます。実操作で全9種の収集、ヒント、再開、連打、音の切り替え、保存失敗、モバイル表示を検証します。
