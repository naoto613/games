# ぴょんたの にじいろ たからさがし

5歳前後向けの、道具としかけを使って探索する宝探しアドベンチャー。既存の「ふーたんを さがせ！」の絵本調の色づかい、「どうぶつ クイズ」の音声案内・失敗してもやり直せる設計、「きらめきプリンセスルーム」のうさぎのぴょんたを参考にしています。

## 遊び方・企画

- 森・浜辺・空の3島 × 3エリア、計9エリア。地面をタップするとぴょんたが歩き、ものをタップすると近づいて調べます。エリアは上の地図から行き来できます。
- 友だちの落とし物を探し、もちものから選んで渡すと、スコップと地図のかけらをもらえます。隠し場所は冒険ごとに変化します。
- 広場と川辺に散らばった3枚の板を集め、長さの合う穴へはめて橋を修理。橋の向こうの3エリア目が開き、もう1枚の地図が手に入ります。
- 森はふくろうの音と光の順番を覚える遊び（3音→4音）、浜辺は浮きが狙いの範囲に来たら魚を釣る遊び（3匹）、空は曲がった風の通り道を回して風車へつなぐ遊び。それぞれの達成で地図をもらえます。
- 友だちの手伝い・橋の修理・島のしかけは好きな順序で進められます。地図が3枚そろうと、2つの目印を組み合わせて宝の位置を推理できます。
- スコップを選んで、目印の間を調べます。正しい場所では土を指でこする／タップして宝箱を掘り出せます。指を動かしても同じ土の連打でもなく、異なる土の領域を7つ掘る必要があります。
- 各島5匹の隠れたちょうちょ、テントやランタンなどの寄り道もあります。宝物は全9種、未取得が優先。ちょうちょは島ごとの最高発見数を記録します。
- ヒントは任意の3段階。待機や間違いで答えを自動表示しません。音の順番を表示する補助、魚の動きを遅くする補助も用意しています。時間切れ・ゲームオーバー・消費アイテムの不足はありません。
- 音は最初オフ。音ボタンで効果音と日本語読み上げを有効にできます。音のしかけにも光の合図があり、音声が使えなくても遊べます。
- 各島の進行を個別に自動保存し、島の切り替えや再読み込みでも再開できます。橋の部品・音の完了ラウンド・釣った魚・風の通り道・掘った土も保存します。
- v1の宝物と音設定を引き継ぎます。旧版のかぎ探しの途中状態は新しい探索には適用しません。v1の保存自体は削除しません。
- ひらがな中心の案内、大きなタップ領域、キーボードでのボタン操作、動きを減らす設定、保存や音声APIが使えない環境に対応しています。

## 起動

ビルド・外部素材・外部フォント・通信は不要。`index.html` を直接開くか、リポジトリのルートで以下を実行します。

```sh
python3 -m http.server 8766
# http://localhost:8766/nijiiro-treasure/
```

`art.js` はオリジナルのSVG、`world.js` は島・エリア・オブジェクト・保存状態の検証、`game.js` は探索・道具・しかけ・保存・音です。`style.css` は共通の画面、`adventure.css` は探索としかけのレイアウトです。ブラウザが旧ファイルを再利用しないよう、読み込みURLにバージョンを付けています。

## 検証

Playwright と Chromium が入った環境で、上記のサーバーを起動して実行します。

```sh
node nijiiro-treasure/tests/state.cjs
node nijiiro-treasure/tests/play.cjs
```

`TREASURE_TEST_URL` で対象URL、`CHROMIUM_PATH` でブラウザの実行ファイルを変更できます。実操作で9回の冒険と全9種の収集、全15匹のちょうちょ、各しかけ、道具の選択、途中再開、島ごとの進行、v1からの移行、移動の中断、保存／音声APIの失敗、スマートフォン／タブレット／PC表示を検証します。
